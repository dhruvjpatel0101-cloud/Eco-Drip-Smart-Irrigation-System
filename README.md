# Eco-Drip-Smart-Irrigation-System
EcoDrip is an IoT-based smart irrigation system that automates plant watering using real-time soil moisture, temperature, and humidity data. Built with Arduino UNO R4 WiFi, sensors, Supabase, and AI-assisted analysis to optimize watering, reduce water wastage, and support healthier plant growth.
